## 关键流程分析

### 1. 侵略系统（世界征服）

位置：`INVASION.ERB`

#### 1.1 可侵略区域

| 区域 ID | 区域名 | 初始侵略度 | 胜利条件 |
|---------|--------|------------|----------|
| FLAG:81/82 | 人类界 | 5000 | 10000 |
| FLAG:86/87 | 精灵界 | 5000 | 10000 |
| FLAG:88/89 | 龙之山脉 | 5000 | 10000 |
| FLAG:90/91 | 天界 | 5000 | 10000 |
| EX_FLAG:101/102 | 天神宮 | - | 特定条件 |

#### 1.2 侵略流程

```
用户选择 [109] 侵略
    ↓
@INVASION
    │
    ├─ 显示各区域侵略进度条
    │
    ├─ 选择目标区域 (0-5)
    │   ├─ [0] 人类界
    │   ├─ [1] 精灵界
    │   ├─ [2] 龙之山脉
    │   ├─ [3] 天界
    │   ├─ [4] 圣灵骑士堡垒
    │   └─ [5] 天神宮
    │
    ├─ 选择派遣怪物 (ITEM:100-189)
    │
    ├─ 执行侵略战斗
    │   ├─ 怪物攻击计算
    │   ├─ 区域抵抗计算
    │   └─ 侵略度增减
    │
    └─ 战斗结果处理
```

#### 1.3 侵略度机制

- 初始值：5000
- 最大值：10000
- 每天减少：0-100（人类界反抗）
- 每次战斗：基于怪物数量和强度

---

### 2. 敌人入侵系统

位置：`ENTER_ENEMY.ERB`

#### 2.1 入侵触发

```
回合结束 (TIME=1)
    ↓
@EVENTTURNEND (EVENT_TURNEND.ERB:93)
    ↓
@ENTER_ENEMY
    │
    ├─ 角色数量限制检查
    │   ├─ 人类界未征服：上限 60
    │   ├─ 精灵界未征服：上限 65
    │   └─ ...
    │
    ├─ 随机选择勇者 ID (1-16)
    │
    ├─ 检查是否已有该角色
    │
    ├─ 创建新勇者角色
    │   ├─ CALL CHAR_MAKE_INPORT (异国勇者判定)
    │   ├─ ADDCHARA
    │   ├─ 设置等级 (基于 FLAG:60)
    │   └─ 设置初始金钱
    │
    └─ 显示入侵消息
```

#### 2.2 勇者等级计算

- 基础等级：`FLAG:60`（初始值根据日期递增）
- 特殊事件触发：
  - 莉莉出现 (`CALL K_11_LILY`)
  - 狂王出现 (`CALL K_34_crazylord`)

---

### 3. 群体战斗系统

位置：`GROUP_BATTLE.ERB`

#### 3.1 战斗流程

```
@GROUP_BATTLE, ARG:0
    │ (ARG:0 = 领队角色ID)
    │
    ├─ 先制攻击 (3次)
    │   └─ 有先制能力的角色优先攻击
    │
    ├─ 攻击循环 (最多99回合)
    │   ├─ 随机选择攻击者顺序
    │   ├─ 攻击者 → @ENEMY_ATTACK
    │   ├─ 目标反击
    │   └─ 死亡检查
    │
    └─ 胜负判定
        ├─ 敌方全灭 → 胜利
        └─ 我方全灭 → 失败
```

#### 3.2 队伍编制

- 领队：CFLAG:531
- 成员1：CFLAG:532
- 成员2：CFLAG:533
