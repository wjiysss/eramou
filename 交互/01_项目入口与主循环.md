# 01_项目入口与主循环

## 功能概述

eraMaouEx 是一个基于 ERB 脚本系统的日文游戏（ERB = ERb Master），核心玩法为"魔王模拟器"——玩家扮演苏醒的魔王，通过调教勇者、侵略扩张、建设地下城等方式统治世界。

游戏采用**回合制**系统，分为上午（TIME=0）和下午（TIME=1）两个时段，每个时段结束后进入回合结束处理（`EVENTTURNEND`）。

## 关键流程分析

### 1. 游戏启动流程

```
启动游戏
    ↓
@SYSTEM_TITLE (TITLE.ERB:1)
    ├─ 显示标题画面（版本、作者信息）
    ├─ [0] 旧的奴隶 → CALL SYSTEM_LOADGAME → 读取存档
    └─ [1] 新的猎物 → CALL RESETDATA → @EVENTFIRST → BEGIN FIRST
```

**输入**：用户选择 0 或 1
**条件**：存档是否存在
**结果**：
- 选择 0：加载存档 → `@EVENTLOAD`
- 选择 1：创建新游戏 → `@EVENTFIRST`

---

### 2. 新游戏初始化 (@EVENTFIRST)

位置：`SYSTEM_DATA.ERB:1-177`

**输入**：新游戏选择
**条件**：FLAG:501（初期奴隶类型）
**结果**：初始化游戏数据

关键初始化内容：
- 初始资金：`MONEY = 10000` pts
- 初始日期：`DAY:1 = 1`（第1天）
- 初始威望：`EX_FLAG:99 = 70`
- 战斗日志配置：`FLAG:5 = 17179934119`
- 主角年龄：`CFLAG:0:451 = 21`

根据 FLAG:501 选择：
- `FLAG:501 == 1`：村娘剧情（固定角色）
- `FLAG:501 == 0`：随机生成勇者（`CALL RAND_CHARA_MAKE`）

### 4. 回合结束处理 (@EVENTTURNEND)

位置：`SYSTEM_DATA.ERB:179-676`

**输入**：TIME 时段结束
**条件**：无（每个时段结束时强制执行）
**结果**：角色状态更新、事件触发

执行顺序：
1. **自动调教格式化**：`CALL FORMAT_AUTOTRAIN`
2. **-party设置**：`CALL PARTY_UNITE`
3. **地城攻略**：对 CFLAG:1 == 2/3 的角色调用 `CALL DUNGEON`
4. **角色恢复**：HP/气力恢复（受装备、素质影响）
5. **装备效果处理**：
   - 魅惑戒指（W:8=6）
   - 洗脑戒指（W:8=15）
   - 经验增加（W:8=10）
6. **自动处刑**：若 FLAG:5 & 8，对低顺从被俘勇者执行
7. **侵略度减少**：人类界/精灵界/龙族/天界的反抗
8. **魔王恢复**：BASE:0:0（HP）和 BASE:0:1（气力）
9. **日常业务**：`CALL BENKI`、`CALL NAEDOKO`、`CALL MARRIAGE_DAY`
10. **自动调教**：`CALL AUTOTRAIN`
11. **新的一天事件**：`CALL EVENT_NEWDAY`（TIME==0 时）

### 5. 状态切换机制

游戏使用 EmuerayERb 的 `BEGIN` 指令切换状态：

| 状态 | 说明 | 切换来源 |
|------|------|----------|
| `TITLE` | 标题画面 | 存档读取后 |
| `FIRST` | 新游戏剧情 | 新游戏开始 |
| `SHOP` | 主菜单/商店 | 回合结束、指令执行完 |
| `TRAIN` | 调教中 | 执行调教指令 |
| `DUNGEON` | 地城探索 | 进入地下城 |

## 模块调用关系

```
TITLE.ERB (@SYSTEM_TITLE)
    │
    ├─ SYSTEM_LOADGAME (新游戏)
    │   └─ EVENTFIRST (SYSTEM_DATA.ERB)
    │       ├─ FIRST_SETTING
    │       ├─ RAND_CHARA_MAKE (随机角色)
    │       └─ BEGIN SHOP
    │
    └─ 读取存档
        └─ EVENTLOAD (SYSTEM_DATA.ERB)
            └─ SYSTEM_LOADEND
                └─ BEGIN SHOP

_DRAW_MAINMENU (@DRAW_MAINMENU)
    │
    ├─ 调用各信息面板函数
    │   ├─ DRAW_HAVEITEMS
    │   ├─ DRAW_HAVETRAPS
    │   ├─ DRAW_DUNGEON_OVERVIEW
    │   └─ DRAW_DUNGEON_DAILY
    │
    └─ 菜单指令 → 相应处理函数

EVENTTURNEND (回合结束)
    │
    ├─ FORMAT_AUTOTRAIN
    ├─ PARTY_UNITE
    ├─ DUNGEON (各地城角色)
    ├─ LVUP (升级检查)
    ├─ 装备效果 (EQUIP_CHECK)
    ├─ 自动处刑 (EXECUTION_MINI)
    ├─ 侵略度处理
    ├─ BENKI / NAEDOKO / MARRIAGE_DAY
    ├─ AUTOTRAIN
    ├─ EVENT_NEWDAY
    └─ BEGIN SHOP
```
