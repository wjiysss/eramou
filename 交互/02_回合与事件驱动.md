# 02_回合与事件驱动

## 功能概述

本模块分析 eraMaouEx 的**回合制系统**和**事件驱动机制**。游戏采用"上午/下午"双时段制，每个时段结束后触发回合结束处理，进而触发各种周期性事件。

---

| 文件路径 | 功能说明 |
|---------|----------|
| `F:\code\eraMaouEx\ERB\EVENT_TURNEND.ERB` | 回合结束主处理，包含 `@EVENTTURNEND` |
| `F:\code\eraMaouEx\ERB\EVENT_NEXTDAY.ERB` | 日期变更事件（跨日时触发） |

| `F:\code\eraMaouEx\ERB\EVENT_BEFORETRAIN.ERB` | 调教开始前事件 |

## 关键流程分析

### 1. 回合时间线总览

```
时段执行 (上午 TIME=0 / 下午 TIME=1)
    ↓
调教/其他操作执行
    ↓
BEGIN TURNEND → @EVENTTURNEND (SYSTEM_DATA.ERB)
    ↓
@EVENTTURNEND (EVENT_TURNEND.ERB:8-139)
    ↓
    ├─ 贩卖/助手判定 (CALL CHECK_SELLASSIABLE)
    ├─ 特殊素质获得 (CALL CHECK_SPECIALSKIL)
    ├─ 妊娠判定 (CALL IN_VAGINA_ALL, CONCEPTION_CHECK_ALL)
    │
    └─ TIME=1（下午结束）时：
        ├─ 卖春妊娠 (CALL IN_VAGINA_EXTRA)
        ├─ 狂王/兽奸妊娠
        ├─ CALL EVENT_NEXTDAY
        ├─ 日期+1，星期循环
        ├─ 若 DAY:2 > 28: CALL EVENT_NEXTMONTH
        ├─ CALL ENTER_ENEMY (勇者入侵)
        └─ CALL AUTO_BUYING (自动购物)
    ↓
BEGIN SHOP → 返回主菜单
```

### 2. 时间变量

| 变量 | 含义 | 位置 |
|------|------|------|
| `DAY:0` | 总经过天数 | `EVENT_TURNEND.ERB:79` |
| `DAY:1` | 当前月份 | `EVENT_NEXTDAY.ERB:3` |
| `DAY:2` | 当前日期 | `EVENT_TURNEND.ERB:81` |
| `DAY:3` | 星期（0-6） | `EVENT_TURNEND.ERB:86` |
| `TIME` | 时段（0=上午，1=下午） | `EVENT_TURNEND.ERB:91` |

### 3. 日期变更事件 (@EVENT_NEXTDAY)

位置：`EVENT_NEXTDAY.ERB:6-73+`

**触发条件**：`TIME == 1`（下午结束）时

**处理流程**：

```
FOR EACH 角色:
    ├─ 不思議の根 + 精液经验 ≥ 150 → 扶她化
    ├─ 反抗刻印3 + 特定条件 → 幼儿退行
    ├─ 恶魔肌肤/羽/尾/眼齐全 → 种族变为魔族
    ├─ 媚药中毒处理
    └─ 灵魂错位处理

├─ 排卵诱发剂效果结束
├─ 熏香使用次数清除
├─ 妊娠/生产/育儿室处理 (CALL NINSIN_MAIN)
└─ 处女检查...
```

---

### 4. 月份变更事件 (@EVENT_NEXTMONTH)

位置：`EVENT_NEXTMONTH.ERB:12-36`

**触发条件**：`DAY:2 > 28`（日期超过28时）

**处理逻辑**：

```
IF DAY:1 == 2:
    月份+1，日期=1
ELSEIF DAY:1 in {4,6,9,11} && DAY:2 > 30:
    月份+1，日期=1
ELSEIF DAY:1 in {1,3,5,7,8,10} && DAY:2 > 31:
    月份+1，日期=1
ELSEIF DAY:1 == 12 && DAY:2 > 31:
    年份+1，所有角色年龄+1
```

---

### 5. 淫乱仪式 (@SABBATH)

位置：`EVENT_SABBATH.ERB:2-229`

**触发条件**：
- `CFLAG:1 == 0`（调教状态外）
- `DAY:2 == 15`（满月）
- `TALENT:242 || TALENT:250`（法术或咒术）
- `TALENT:76 == 1`（淫乱）

**效果**：根据角色性别和素质，获得大量经验值和珠

---

### 6. 调教开始前事件 (@PRITRAIN_MESSAGE)

位置：`EVENT_BEFORETRAIN.ERB:6-206`

**触发条件**：每次调教开始时

**处理内容**：
- 调教经验 +1（`CFLAG:10`）
- 第一次调教特殊消息
- 根据角色性格显示不同服装状态
- 妊娠中角色显示警告
- 助手介绍

---

### 7. 调教结束后事件

位置：`EVENT_AFTERTRAIN.ERB`

#### 7.1 死亡检查 (@CHARADEAD_CHECK)

```
IF BASE:0 <= -1:
    ├─ 魔王死亡 → GAME OVER / 转移至其他角色
    ├─ 死亡口上触发
    ├─ 角色删除
    └─ 击杀数+1 (FLAG:31)
```

#### 7.2 调教后行为检查 (@SELF_CHECK)

```
├─ 性交检查 (AFTERTRAIN_SEX_CHECK)
│   条件：爱/淫乱、性交经验≥30、非处女、非男人
│   效果：V经验、珠增加
│
├─ 肛门性交检查 (AFTERTRAIN_ANALSEX_CHECK)
│   条件：爱/淫乱、性交经验≥30
│   效果：A经验、珠增加
│
├─ 百合行为检查 (AFTERTRAIN_LESBIANSEX_CHECK)
│   条件：助手存在、百合中毒、百合气质≥2
│   效果：百合经验、珠增加
│
├─ 自慰检查 (AFTERTRAIN_MASTURBATION_CHECK)
│   条件：自慰中毒、阴蒂感觉≥3、欲望≥2
│   效果：自慰经验、珠增加
│
└─ 兽奸检查 (AFTERTRAIN_BEASTSEX_CHECK)
    条件：兽奸中毒≥2、兽奸经验≥50、有野狗
    效果：兽奸经验、珠增加
```

### 8. 自动调教系统 (@AUTOTRAIN)

位置：`EVENT_AUTOTRAIN.ERB`

**触发条件**：`CFLAG:666 != 0`（标记为自动调教角色）

**执行流程**：

```
FOR EACH 自动调教角色:
    ├─ CALL FORMAT_AUTOTRAIN (初始化)
    ├─ CALL BEFORE_AUTOTRAIN (源重置)
    ├─ 自动调教内容执行
    ├─ CALL AFTER_AUTOTRAIN (后处理)
    │   ├─ 善良值变化 (KARMA)
    │   ├─ 常时发情积累
    │   ├─ 珠计算 (JUEL_CHECK_MAIN)
    │   └─ 自动升级 (AUTO_ABLUP)
    └─ 等待/强制停止
```
