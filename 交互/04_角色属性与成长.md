## 关键流程分析

### 1. 角色创建流程

位置：`CHAR_MAKE.ERB:42-160`

```
用户选择 [1] 新的猎物
    ↓
@RAND_CHARA_MAKE
    │
    ├─ 随机选择角色 NO (1-16)
    ├─ 检查角色是否存在
    ├─ 调用 CHAR_MAKE_INPORT (异国勇者判定)
    │
    ├─ ADDCHARA 添加角色
    ├─ CALL ADDCHARA_EX 初始化角色
    │
    ├─ 设置性格 (CHARACTER)
    ├─ 设置发色 (HAIRCOLOR)
    │
    ├─ 显示角色信息
    ├─ 玩家确认
    │
    └─ 设置 CFLAG:1 = 0 (囚禁状态)
```

**角色 ID 范围**：
- 1-16：普通勇者
- 17：玛奥（村娘）
- 20-23：扑克牌
- 24：莉莉
- 31-35：贡品
- 201-210：精英部下

### 2. 能力（Ability）系统

位置：`ABL.ERB` 和 `F:\code\eraMaouEx\CSV\Abl.csv`

#### 2.1 能力分类

| 编号 | 类别 | 能力名称 |
|------|------|----------|
| 0-9 | 性感系 | 阴蒂感觉、乳房感觉、V感觉、肛门感觉 |
| 10-19 | 技术系 | 顺从、欲望、技巧、侍奉技术、性交技术、话术、侍奉精神、露出癖 |
| 20-29 | 特殊性癖 | 抖S气质、抖M气质、百合气质、断背气质 |

#### 2.2 能力提升流程

```
用户选择能力提升
    ↓
@SHOW_ABLUP_SELECT (ABL.ERB:29)
    │
    ├─ 显示可提升的能力列表
    ├─ 检查性别限制（男性无法提升V感觉、百合气质）
    │
    └─ 用户选择能力编号
        ↓
    @DECIDE_ABLUP (ABL.ERB:113)
        │
        ├─ 调用 @DECIDE_ABLUP{n} 检查珠是否足够
        └─ 调用 @CORE_ABLUP{n} 执行提升
```

### 3. 等级（Level Up）系统

位置：`LVUP.ERB`

#### 3.1 经验需求

```
IF 角色 == MASTER (魔王):
    升级所需经验 = LV × 100 + 10
ELSE IF TALENT:220 (精英):
    升级所需经验 = LV × 20 × 2 + 10
ELSE (普通勇者):
    升级所需经验 = LV × 10 + 10
```

#### 3.2 升级效果 (@ST_UP)

```
CFLAG:9 (等级) +1
CFLAG:13 (攻击) +1
CFLAG:14 (防御) +1
+ 随机加成:
    - 50% 概率攻击+1
    - DAY >= 100 时攻击+0-2，防御+0-2
    - 龙族: 攻击+0-1，防御+0-1
    - 矮人: 防御+0-1
    - 史莱姆: 防御+0-1
    - 触手: 攻击+0-1
MAXBASE:0 (HP) +10
MAXBASE:1 (气力) +10
```

## 关键变量/标志位

### 角色数据
| 变量 | 说明 |
|------|------|
| `NO:ARG` | 角色基础ID |
| `CFLAG:ARG:1` | 角色状态（0=囚禁，2=迷宫内，3=迎击中） |
| `CFLAG:ARG:9` | 等级 |
| `CFLAG:ARG:13` | 攻击力 |
| `CFLAG:ARG:14` | 防御力 |
| `CFLAG:ARG:451` | 年龄 |
| `CFLAG:ARG:452` | 真实年龄 |

### 能力与经验
| 变量 | 说明 |
|------|------|
| `ABL:ARG:n` | 能力等级 (n=能力ID) |
| `EXP:ARG:n` | 经验值 (n=经验ID) |
| `JUEL:ARG:n` | 珠数量 (n=珠ID) |
| `TALENT:ARG:n` | 素质 (n=素质ID) |

### 等级提升
| 变量 | 说明 |
|------|------|
| `EXP:ARG:80` | 迷宫经验（用于等级提升） |
| `MAXBASE:ARG:0` | HP 上限 |
| `MAXBASE:ARG:1` | 气力上限 |

```
角色创建
    │
    └─ @RAND_CHARA_MAKE
        ├─ ADDCHARA
        ├─ ADDCHARA_EX
        ├─ SET_CHARASTERISTIC

能力提升
    │
    └─ @SHOW_ABLUP_SELECT
        ├─ @DECIDE_ABLUP
        │   └─ @DECIDE_ABLUP{n}
        └─ @CORE_ABLUP{n}

等级提升
    │
    └─ @LVUP
        └─ @ST_UP
            ├─ CFLAG:9/13/14 修改
            └─ MAXBASE 修改

自动提升
    │
    └─ @AUTO_ABLUP (FLAG:5 & 36)
        └─ @AUTO_ABLUP_CORE
```
