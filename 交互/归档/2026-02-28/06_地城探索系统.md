## 关键流程分析

### 1. 地城探索主流程

位置：`DUNGEON.ERB`

```
用户选择 [102] 地下城
    ↓
@DUNGEON, ARG:0
    │
    ├─ 检查是否正在行动 (CFLAG:530)
    │   └─ 迎击中的潜入行动
    │
    ├─ 初始化
    │   ├─ SIDEA = CFLAG:531 (队友1)
    │   ├─ SIDEB = CFLAG:532 (队友2)
    │   └─ FLOOR = CFLAG:501 (当前阶层)
    │
    ├─ 前进计算 (WALK)
    │   ├─ 基础值：RAND:20
    │   ├─ 速度加成 (LOCAL:0-5)
    │   ├─ 装备效果 (W:8=17)
    │   └─ 迷惑状态惩罚
    │
    ├─ 房间事件判定
    │   └─ FLAG:400 ? 活动地图 : 普通地图
    │
    └─ 循环处理 (TURN = 0-4)
        ├─ 遭遇判定
        ├─ 战斗/事件
        └─ 结果结算
```

### 2. 怪物战斗系统

位置：`DUNGEON_BATLLE.ERB`

#### 2.1 敌人选择

```
IF FLAG:502 == 1 (2D模式):
    废弃
ELSE IF CFLAG:1 == 12 (活动地城):
    调用 CAMPAIGN_MONSTER_LIST
ELSE:
    怪物ID = (当前阶层-1) × 10 + 100 + RAND:5
    8层以上 10% 几率遇到BOSS (191-193)
```

#### 2.2 战斗流程

```
@DUNGEON_PARTY_BATTLE, ARG:0
    │
    ├─ 敌人选择 (4个敌人)
    │
    ├─ 先制攻击 (3次)
    │   └─ 有先制能力的角色优先
    │
    ├─ 攻击循环 (最多6回合)
    │   ├─ 领队 → 成员A → 成员B → 领队...
    │   ├─ 攻击计算
    │   └─ 反击计算
    │
    └─ 胜负判定
        ├─ 敌人全灭 → 获得经验/掉落
        └─ 我方全灭 → 被俘虏/死亡
```

### 3. 怪物召唤系统

位置：`SUMMON_MONSTER.ERB`

#### 3.1 召唤条件

```
@SUMMON_MONSTER(ARG)
    ├─ ARG == 0: 正常召唤
    ├─ ARG == -1: 弱召唤 (数量减半)
    └─ ARG > 0: 出产 (妊娠相关)
```

#### 3.2 召唤数量计算

```
基础数量: 5
+ 魔王等级加成:
  - LV >= 10: +1
  - LV >= 30: +1
  - LV >= 50: +1
  - LV >= 70: +1
  - LV >= 100: +1
+ 魔界知识: +1
+ 淫魔知识: +1
+ 菲亚公主: ×1.5
+ 银黑桃忍军: ×1.5
```

#### 3.3 怪物类型

根据阶层决定：
- 100-109: 第1层怪物
- 110-119: 第2层怪物
- ...
- 190-193: BOSS级怪物
