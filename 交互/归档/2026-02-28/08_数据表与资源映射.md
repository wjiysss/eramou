## 数据表详解

### 1. GameBase.csv - 游戏基础信息

```
バージョン = 920
タイトル = ERA_MAOU_EX
作者 = 「人人为我，我为人人」
製作年 = 2011 - 2018
```

### 2. Abl.csv - 能力表

| ID | 名称 | 类别 |
|----|------|------|
| 0 | 阴蒂感觉 | 性感 |
| 1 | 乳房感觉 | 性感 |
| 2 | 私处感觉 | 性感 |
| 3 | 肛门感觉 | 性感 |
| 10 | 顺从 | 技术 |
| 11 | 欲望 | 技术 |
| 12 | 技巧 | 技术 |
| 20 | 抖S气质 | 特殊性癖 |
| 21 | 抖M气质 | 特殊性癖 |
| 30 | 性交中毒 | 中毒 |

### 3. Talent.csv - 素质表

素质 ID 范围：
- 0-9: 基本（处女、童贞、崩坏）
- 10-19: 性格（胆怯、反抗、坦率等）
- 20-29: 性向（克制、开放等）
- 30-39: 贞操（看重贞操、看轻贞操等）
- 40-49: 体质（怕痛、易湿等）
- 50-59: 技术（调合知识等）
- 60-69: 洁癖（献身的等）
- 70-79: 诚实（接受快感等）
- 80-89: 性癖（淫乱、施虐狂等）
- 90-99: 魅惑（魅惑、威压感等）
- 100+: 身体特征

### 4. Train.csv - 调教指令表

| ID范围 | 类别 |
|--------|------|
| 0-9 | 爱抚系 |
| 10-19 | 道具系 |
| 20-29 | 性交系 |
| 30-39 | 奉仕系 |
| 40-49 | SM系 |
| 50-59 | 道具系2 |
| 60-69 | 组合系 |
| 100+ | 特殊系 |

### 5. Item.csv - 物品表

格式：`ID,名称,价格,备注`

示例：
```
0,振动宝石,200
1,壶虫,500
10,鞭,200
22,野狗,3000,;兽奸调教可
39,【魔界知识】,100000
```

### 6. Palam.csv - 珠表

珠用于调教后分配点数，常见类型：
- 0: 阴蒂/阴茎
- 1: 阴道
- 2: 肛门
- 3: 润滑
- 4: 恭顺
- 5: 欲望
- 8: 习得
- 10: 反感

## 数据加载机制

游戏中 CSV 数据通过以下方式加载：

```
@CHARA_NAME_INIT
    ↓
加载角色名 (NAME:n)

@EX_TALENTNAME_INIT
    ↓
加载 EX 素质名
```
