### 3. 角色贩卖系统

位置：`SELL_CHARA.ERB`

#### 3.1 贩卖条件判定 (@CHECK_SELLASSIABLE)

```
贩卖条件：
├─ 顺从 + 欲望 >= 6
├─ C/V/A/B感觉至少一个 >= 3
├─ 有反抗/刚强时顺从 >= 4
├─ 有克制/压抑/抵抗时欲望 >= 4
└─ 以下任一条件：
    - 技巧 >= 3 且侍奉精神 >= 3
    - 露出癖 >= 3 且自慰中毒 >= 2
    - 抖M气质 >= 3
    - C+V+A+B感觉总和 >= 13
    - 顺从 >= 5 或 欲望 >= 5
```

#### 3.2 贩卖价格计算 (@ESTIMATE_CHARA)

```
基础价格 = LV × 100
+ 能力加成：
  - 顺从等级 × 50
  - 欲望等级 × 30
  - 技巧等级 × 20
  - 各感觉等级 × 10
+ 特殊加成：
  - 淫乱：+500
  - 爱慕：+300
  - 处女：+200
- 素质修正：
  - 崩坏：-50%
```

### 4. 处刑系统

位置：`EXECUTION.ERB`

#### 4.1 处刑选项

```
处刑方式 (RESULT 0-7):
├─ [0] 流放出地下城
├─ [1] 公开处刑
├─ [2] 博物馆展品
├─ [3] 猎奇处刑
├─ [4] 做成肉便器
├─ [5] 士兵化
├─ [6] 固定示众
└─ [7] 消除记忆后释放
```

#### 4.2 处刑对象条件

```
可选对象 (CFLAG:1 == 0 或 7):
├─ 非收藏品 (!EX_TALENT:1)
└─ 或 收藏品可出售 (EX_TALENT:2 && EX_FLAG:9000 & 1)
```

#### 4.3 批量处刑

支持批量选择处刑对象（补丁修改）
